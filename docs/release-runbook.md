# Ray 发布与恢复

## 发布边界

- 静态站仍由 GitHub Pages 发布；API 使用 Cloudflare Worker 与 D1。
- PR 必须通过 `verify`：资源/语法/秘密模式检查、Node 回归、独立 Chromium 主页和游戏回归。主分支不接收未经检查的发布。
- 后端使用本机私有版本库和同轮验证记录；公开 CI 不访问凭据或生产 D1。
- 后端与前端共享存档 schema 源，私有发布工具校验副本一致。旧 `/auth/me`、`/game-saves/*` 私人接口返回升级要求；不要恢复旧客户端写入。
- 正式顺序为恢复点、向前兼容迁移、经过测试的 v2 Worker、主机范围边缘规则、通过 CI 的前端发布、匿名线上复核。

## 数据与失败行为

用户 ID、应用 ID 和 schema 构成本地命名空间。退出未被服务器确认时锁定本机私人界面，不能把断网当成服务器会话失效。已有无归属存档、聊天旧键保留，不自动上传。

存档使用 IndexedDB 事务、本地版本和跨页通知。每个云请求快照固定请求 ID、基准 revision 和校验值；只有精确 ACK 才确认对应快照。版本冲突保留副本，需要用户选择时不得猜测余额或棋盘。

聊天及字幕在上游前预占额度；确定拒绝可以释放，超时或结果不明不自动重放。字幕按服务端验证的 WAV 样本时长计量。普通会员现有 10 次聊天、30 秒字幕额度不在本次升级中更改。

## Service Worker

三个历史 SW 注册地址都保留安全更新。仅缓存白名单静态资源，不缓存任何 API；安全控制器握手在旧项目缓存清理之后完成。页面导航允许离线壳，脚本/JSON 失败不能回退成 HTML。

完全离线的旧浏览器不能被服务器立即清理。恢复网络并取得安全 SW 之前，新客户端暂停私人同步；未打开的浏览器不能算已升级。不要清空全站存储或注销其他项目的 SW。

## 运行与回退

私有工具 `channel.py status` 只读，`pause/resume` 只改开关并校验源码/配置不变。`GAME_SAVE_WRITES_ENABLED=false` 暂停云写入但保留本机和安全读取；完整命令及环境保护在私有后端 README。

出现串账号、错误 ACK 或存档校验失败，停止相关写入、保留队列和副本，前向修补或发布最近的安全兼容版本。禁止回滚到已知缓存私人 API、无账号隔离或无条件覆盖存档的旧代码。

D1 迁移保留旧表。数据库恢复与代码回退不同，整库恢复可能丢失升级后的数据，必须另行确认时间窗口和影响。在隔离库验证恢复，优先定向修复。生产导出文件、凭据和实际用户内容不得写入本仓库。

## 传输与验证限制

2026-09-08 检查发现 Pages 源站证书不匹配 `rayalex.cn`。Full (strict) 必须等待源站证书修复；不得用修改共享区域全部主机的 TLS 策略绕过范围限制。DNS 维护、套餐升级和 HSTS 需要满足各自门禁，不能把 HTTPS 边缘证书视为回源证书已验证。

本地验证使用合成账号、假麦克风和模拟上游，不发送真实邮件或调用付费模型。Linux Chromium 和 390/320px 截图不能替代 Safari/WebKit、真机麦克风、系统软键盘或真实用户性能指标。日志仅含请求 ID、粗粒度路由、状态和耗时；运行日志不等于已配置长期监控。
